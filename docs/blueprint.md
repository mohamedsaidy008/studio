# **App Name**: OptimalCP

## Core Features:

- Progressive Learning Roadmap: An Arabic-first roadmap controlled by admins that guides trainees from basics to professional competitive programming through curated lessons.
- Categorized Problem Bank: A repository of problems categorized by topics (Greedy, Math, DP, etc.) with external integration for platforms like Codeforces.
- Gamification & Ranking System: A system rewarding XP for solving problems, moving users through ranks (Beginner to Legend) with a '🔥' daily streak indicator.
- Multi-Role Access Control: Strict permission levels for four distinct roles: Admins (full control), Problem Setters (content creation), Trainees (learning/solving), and Visitors (viewing only).
- Global Leaderboard: A dynamic leaderboard that ranks trainees based on total XP and problem-solving consistency to encourage healthy competition.
- AI Logic Mentor: An AI tool that analyzes trainee code submissions to provide logic-based hints and explanations for failed test cases without giving the direct answer.
- Advanced Content & User Dashboard: A comprehensive interface for Admins and Setters to manage bilingual lessons, embedded YouTube videos, rich text explanations, and user statistics.
- Personal Analytics Profile: A private dashboard for trainees to track their statistics, heatmaps of activity, and current rank progression.

## Style Guidelines:

- Strict monochrome palette: Pure White (#FFFFFF) for light mode and Deep Charcoal (#121212) for dark mode. No blue tones allowed.
- Accents: Vibrant Emerald Green (#00C853) for successes and XP gains; Crimson (#D50000) for errors or failing tests.
- Primary Font: 'Tajawal' for all Arabic headlines and body text to ensure modern readability. Code Font: 'Fira Code' for snippets.
- Right-to-Left (RTL) focused layout for native Arabic experience, utilizing a clean grid system for data-heavy dashboards.
- Minimalist outline icons for navigation, with colored status indicators (flame for streaks, trophies for ranks).
- Subtle transitions between Light and Dark modes and smooth progress bar increments for XP updates.
